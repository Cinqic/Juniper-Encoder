# Data and rights

`manifests/sources/approved.json` contains two immutable, first-party sources owned by Cinqic. Public availability is not treated as a license. Each source has a reviewed checksum, rights evidence, attribution, permitted use, redistribution status, language/domain, and exclusions. The 3,113-byte seed fixture remains a routing-contract fixture. The repository technical snapshot is a separate `training_only` source generated by `scripts/build_first_party_corpus.py`; it contains no supervised labels and is excluded from the routing evaluation freeze while remaining eligible for tokenizer/foundation training.

The materialized frozen routing manifest excludes tokenizer-only records before partitioning and retains provenance-preserving deterministic cleaning, duplicate-family grouping, and disjoint assignments for the general routing fixture. The calibration subset remains insufficient for quality claims. Held-out capability identities and their example families must remain outside tokenizer training, MLM, supervised training, hard-negative mining, and synthetic generation. The Apache-2.0 repository license applies to the repository-owned snapshot; it does not label unrelated corpus data.
