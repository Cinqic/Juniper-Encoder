# Data and rights

`manifests/sources/approved.json` is intentionally empty. Public availability is not treated as a license. Each future source needs an immutable revision/checksum, rights evidence, attribution, permitted use, redistribution status, language/domain, and exclusions before acquisition.

Processed records must retain provenance and original hashes, use deterministic cleaning and duplicate-family grouping, and produce disjoint train/development/calibration/test manifests. Held-out capability identities and their example families must remain outside tokenizer training, MLM, supervised training, hard-negative mining, and synthetic generation. The Apache-2.0 repository license does not label a mixed training corpus.
